# Автономная сборка (без сервера)

Обычная сборка — клиент к Core Backend. Автономная (`OFFLINE_MODE`) работает
вообще без сети: истории, картинки, музыка и шрифты лежат внутри APK, а
прогресс, алмазы, профиль, статистика и достижения хранятся на устройстве.

## Сборка APK

1. Контент — из репозитория бэкенда (база не нужна):

   ```bash
   make export-content
   ```

   Пишет `assets/content/` (`content.json` + медиа).

2. Шрифты — один раз:

   ```bash
   python tool/fetch_offline_fonts.py
   ```

   Пишет `assets/google_fonts/` (Manrope и шрифты скинов плеера, лицензия OFL).

3. Конфиг: скопировать `config/.env.offline.example.json` в
   `config/.env.offline.json`.

4. Сборка:

   ```bash
   flutter build apk --release --flavor offline --target-platform android-arm64 --dart-define-from-file=config/.env.offline.json
   ```

   Результат — `build/app/outputs/flutter-apk/app-offline-release.apk`.
   Без `--target-platform` получится универсальный APK (больше, зато
   ставится и на эмулятор x86_64). Подпись — отладочным ключом: годится для
   установки вручную, не для магазина.

Обе папки ассетов сгенерированы и в git не хранятся (кроме `.gitkeep`:
каталог, перечисленный в `pubspec.yaml`, обязан существовать). В обычные
сборки они не попадают — в `pubspec.yaml` у них `flavors: [offline]`. При
добавлении истории с новыми папками медиа их нужно дописать туда же:
каталоги ассетов не рекурсивны.

## Как это устроено

Подмена происходит на уровне репозиториев (`lib/features/offline/`):
`offlineModeOverrides` подставляет локальные реализации `StoryRepository`,
`WalletRepository`, `UserRepository`, `StatsRepository`,
`AchievementsRepository`, `AuthRepository`. Экраны, нотифаеры и плеер — тот
же код, что и в сетевом режиме.

- `BundledContent` читает `content.json` теми же моделями, что и ответы API.
- `BundledStoryRepository` повторяет правила сервиса историй бэкенда:
  платные выборы и разблокировка сцен списывают алмазы, одноразовые выборы
  исчезают после использования, прогресс идёт по выбранной ветке.
- Медиа адресуется URL вида `asset:assets/content/...`;
  `core/media/media_source.dart` — единственное место, где сетевой URL
  отличается от ассета.
- Состояние игрока — JSON в `shared_preferences` (`LocalStore`). Удаление
  приложения его стирает.

## Чего нет в автономном режиме

- Свободного диалога с ИИ-персонажем — он работает на сервере. Кнопка
  «Поговорить» не показывается, достижения за диалоги не выдаются.
- Аккаунтов и синхронизации: игрок один, вход не нужен.
- Покупок: «Получить» в магазине просто начисляет алмазы.
- Обновления историй «по воздуху»: новый контент — новая сборка.
